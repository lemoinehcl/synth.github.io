# Python-to-Web Audio Synthesizer

A hybrid synthesis project that parses MusicXML scores in Python, renders them using a custom Digital Signal Processing (DSP) engine, and plays them in real-time via a JavaScript Web Audio frontend.

🎹 **[Try it Here!](https://lemoinehcl.github.io/synth.github.io/)**

## Overview
The project is split into two halves:
1. **The Python Engine:** Parses sheet music, calculates tempo/dynamics, and renders high-fidelity `.wav` files and `.json` note data.
2. **The Web App:** A JavaScript reimplementation of the DSP engine that allows users to play notes in real-time, adjust synthesizer parameters, and listen to pre-rendered scores.

## Structure
*   `main.py`: The entry point for the Python engine. Run this to render `.mxl` files into `.wav` and `.json`.
*   `src/`: Contains the core Python DSP engine.
    *   `oscillator.py`: Generates raw waveforms (Sine, Square, Triangle, Sawtooth, Noise) and handles FM synthesis.
    *   `modulator.py`: Handles ADSR envelopes, wavefolding, and peak normalization.
    *   `reader.py`: Uses `music21` to parse MusicXML, handle dynamics, and sequence the audio timeline.
*   `play/`: The frontend web application (HTML, CSS, JavaScript Web Audio API).
*   `examples/`: Contains sample `.mxl` files to test the Python engine.
*   `output/`: Generated `.wav` and `.json` files (created when you run `main.py`).
*   `audio/`: Rendered audio files used for the portfolio website.
*   `images/`: Plots and diagrams used in the documentation.
*   `scores/`: JSON files used by the web playground to play pre-rendered pieces.

## How it works
* Score Parsing: The Python engine reads MusicXML files, stripping out hidden padding and calculating the exact timing of notes and chords, as well as interpolating dynamics (crescendos/decrescendos).

* DSP: Each note is generated by summing up to 4 oscillators. The engine supports Phase Modulation (FM Synthesis) for complex harmonics, a periodic wavefolder for distortion, and ADSR envelopes.

* Web Synth: The play/ directory contains a JavaScript version of the DSP engine. It utilizes the Web Audio API to allow real-time polyphonic playback via mouse or a MIDI controller.
